# Microsoft Threat Modeling Tool → Threat Composer Import Mapping

This document is the field-mapping reference for importing a Microsoft Threat Modeling Tool (TMT) '.tm7' model into Threat Composer (TC). It records how each piece of TMT data maps to a TC field, so nothing semantic is silently dropped, inferred, or reclassified.

**Scope and sources.** The import reads two inputs: the '.tm7' model (data) and a TMT-generated Full Report HTML (the DFD images). It is a data import, not a geometry import — diagram layout/coordinates/styling are ignored. Supporting narrative documents (Word/text/Markdown) are imported separately and are not covered here.

The '.tm7' is .NET DataContractSerializer XML. Values below are TMT element names; TC targets are the fields of a TC threat ('TemplateThreatStatement') and workspace entities. A threat's category/title template are resolved from the TMT Knowledge Base via the threat's 'TypeId'.

---

## Threats

Each TMT threat instance maps to one TC threat.

| TC field | TMT source | Rule |
| --- | --- | --- |
| 'id' | — | new UUID v4 |
| 'numericId' | threat 'Id' (integer) | preserve; if missing or duplicated, allocate an unused numeric id and warn |
| 'statement' | threat 'properties.Title' | verbatim. If absent, fall back to the Knowledge Base 'ThreatType.ShortTitle' template with '{source.Name}' / '{flow.Name}' / '{target.Name}' resolved from the referenced DFD elements. Block import if still empty or unresolved placeholders remain |
| 'status' | threat 'State' | see Status mapping below |
| 'metadata' → 'Priority' | threat 'Priority' | see Priority mapping below |
| 'metadata' → 'STRIDE' | 'ThreatType.Category' (via 'TypeId') | see STRIDE mapping below |
| 'metadata' → 'custom:TMT *' | threat fields / properties | see Custom TMT metadata below |
| grammar fields ('threatSource', 'prerequisites', 'threatAction', 'threatImpact', 'impactedGoal', 'impactedAssets') | — | NOT inferred; left empty (TMT has no equivalent structured fields) |

### Status mapping

TMT 'State' → TC 'status':

| TMT 'State' | TC 'status' |
| --- | --- |
| 'Mitigated' | 'threatResolved' |
| 'NotApplicable' | 'threatResolvedNotUseful' |
| 'AutoGenerated' | 'threatIdentified' |
| 'Migrated' | 'threatIdentified' |
| 'NeedsInvestigation' | 'threatIdentified' |
| 'NeedsMitigation' | 'threatIdentified' |

The original 'State' is also preserved as 'custom:TMT State'. (Note: in the TMT enum 'Migrated' aliases 'AutoGenerated' and 'NeedsMitigation' aliases 'NeedsInvestigation', so serialized '.tm7' files carry only the four canonical names; all four non-mitigated/non-N/A states map to 'threatIdentified'.)

### Priority mapping

TMT 'Priority' → TC 'Priority' metadata value:

| TMT 'Priority' | TC 'Priority' |
| --- | --- |
| 'High' | 'High' |
| 'Medium' | 'Medium' |
| 'Low' | 'Low' |
| other / empty | omit 'Priority' metadata |

### STRIDE mapping

The threat's category comes from its 'ThreatType.Category' (resolved via 'TypeId'). TMT uses the single STRIDE letters, which map directly to the TC 'STRIDE' metadata value (a string array):

| 'ThreatType.Category' | TC 'STRIDE' | Meaning |
| --- | --- | --- |
| 'S' | '["S"]' | Spoofing |
| 'T' | '["T"]' | Tampering |
| 'R' | '["R"]' | Repudiation |
| 'I' | '["I"]' | Information disclosure |
| 'D' | '["D"]' | Denial of service |
| 'E' | '["E"]' | Elevation of privilege |
| any other / ambiguous value | omit 'STRIDE' + warn | — |

The original category value is always preserved as 'custom:TMT Category'.

### Custom TMT metadata ('custom:TMT *')

Preserved as TC threat metadata entries so nothing is lost. Fixed entries:

| TC metadata key | TMT source |
| --- | --- |
| 'custom:TMT Threat ID' | threat 'Id' |
| 'custom:TMT Category' | 'ThreatType.Category' |
| 'custom:TMT State' | threat 'State' |
| 'custom:TMT Description' | 'properties.UserThreatDescription' |
| 'custom:TMT Interaction' | 'properties.InteractionString' |
| 'custom:TMT Diagram' | DFD surface name (via threat 'DrawingSurfaceGuid') |
| 'custom:TMT Justification' | 'properties.StateInformation' (present only on reviewed threats) |

Additionally, **every other non-empty threat property** is preserved as 'custom:TMT <label>', where '<label>' is the Knowledge Base display label ('ThreatMetaDatum.Label') for that property name, falling back to the raw property name. If a label collides with a fixed entry above (for example a 'UserThreatCategory' property whose label is 'Category', colliding with 'custom:TMT Category'), the raw property name is appended to keep the key unique (for example 'custom:TMT UserThreatCategory'). TMT values are never packed into TC 'Comments'.

### Failure policy

- A threat with no resolvable 'statement'/title, or missing identity, **blocks the import** (nothing is imported partially).
- Missing *optional* metadata produces a warning, not a block.
- Threats are never silently skipped, truncated, or reclassified.

## Data Flow diagrams

Each non-empty TMT drawing surface becomes a named TC Data Flow diagram. The diagram image is taken from the matching TMT Full Report entry (by order, with name as a cross-check), not rendered from '.tm7' geometry. Empty surfaces are reported as a warning (the Full Report omits them).

---

## Model information

TMT 'MetaInformation' and 'Notes' map to a 'Microsoft TMT Model Information' block on the TC Application description:

| TC (Application description block) | TMT source |
| --- | --- |
| Threat model name | 'MetaInformation.ThreatModelName' |
| High-level system description | 'MetaInformation.HighLevelSystemDescription' |
| Owner | 'MetaInformation.Owner' |
| Reviewer | 'MetaInformation.Reviewer' |
| Contributors | 'MetaInformation.Contributors' |
| Assumptions | 'MetaInformation.Assumptions' |
| External dependencies | 'MetaInformation.ExternalDependencies' |
| Notes (ordered by id, with author and date) | 'Notes' ('Note.Id' / 'Note.Message' / 'Note.AddedBy' / 'Note.Date') |

The workspace and Application name default to 'ThreatModelName', falling back to the '.tm7' filename (without extension) when empty.

---

## Not mapped

- **Diagram geometry / rendering:** element coordinates, sizes, connector routes, ports, zoom, stroke/dash, icon image streams. (Data-only import; DFD images come from the Full Report.)
- **TC grammar fields:** 'threatSource', 'prerequisites', 'threatAction', 'threatImpact', 'impactedGoal', 'impactedAssets' — never inferred from TMT text.
- **TMT model-validation results, Profile, and Knowledge Base element/attribute definitions** — not represented as TC entities (the Knowledge Base is consulted only for title templates and property display labels).
